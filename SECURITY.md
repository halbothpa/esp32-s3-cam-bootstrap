# Security

This public repository is an immutable bootstrap pointer, not a security or
authentication boundary. Everyone can read, clone and fork public content.

Expected contents are exactly `adopt.yaml`, `README.md`, `SECURITY.md`,
`LICENSE`, and `.github/CODEOWNERS`. There must be no Actions workflow, binary,
implementation source, token or secret value.

Do not open a public issue with credentials or private repository details.
Report a suspected leak privately to the owner and revoke the affected token
immediately.
